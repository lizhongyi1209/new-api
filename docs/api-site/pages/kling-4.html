可灵 4.0 与 4.0 Flash 的文生视频、图生视频（多关键帧）和 Omni 多素材 / 视频编辑。路径、请求体和响应与可灵官方一致，只需在路径前加 /kling。 POST /kling/<类型>/kling-4.0，返回 data.id GET /kling/tasks?task_ids=… succeeded 后读取 outputs[].url

这个接口做什么？

用可灵 4.0 或 4.0 Flash 生成视频。用法和可灵官方完全一样，只是路径前多一个 /kling，Base URL 换成本站。模型由路径决定，请求体里不用写 model。

你需要提供的信息

做什么
选路径：文生视频 text-to-video、图生视频 image-to-video、多素材与编辑 omni-video。
用哪个版本
路径末尾 kling-4.0 或 kling-4.0-flash。Flash 只支持 720p、3–20 秒。
想要什么画面
文生视频填 prompt；其余两种用 contents 数组放提示词和素材。
时长与分辨率（可选）
settings.duration、settings.resolution、settings.aspect_ratio。

怎么拿到结果

状态
submitted、processing 继续等待；succeeded 成功；failed 失败。
视频地址
data[].outputs[].url，通常保留 30 天，请及时保存。
  1. 按需求选路径 POST /kling/{text-to-video|image-to-video|omni-video}/{kling-4.0|kling-4.0-flash}，请求体不传 model。记录 data.id。
  2. Flash 只用 720p、3–20 秒；4.0 时长 3–30 秒。
  3. 定期 GET /kling/tasks?task_ids={id}，submitted 或 processing 时继续查询。
  4. succeeded：把 outputs[].url 返回给用户，提醒约 30 天有效。
  5. failed：把 message 告诉用户，不要自动重试。
Flash：请求体与 4.0 相同，只把路径里的 kling-4.0 换成 kling-4.0-flash。只支持 720p（默认也是 720p），时长 3–20 秒。不要传 1080p，也不要超过 20 秒。

通用设置

字段类型必填说明
settings.durationinteger否4.0：3–30 秒；Flash：3–20 秒。有填写值时以填写值为准。省略时识别提示词时长；Omni 若仍没有，则取 base_video 时长（取整），否则 10 秒。计费看 usage.output_duration。
settings.resolutionstring否4.0：720p 或 1080p，默认 1080p。Flash 只支持 720p，默认也是 720p。
settings.aspect_ratiostring否仅文生视频和 Omni：21:9、16:9、9:16、1:1。Omni 另支持 adaptive。图生视频不能传。
settings.audiostring否仅 Omni。native（默认）按画面生成音频；original 保留输入视频原声。original 不能同时引用 voice，且至少要有一条 base_video 或 feature_video。有 base_video 用它的声音，否则用 contents 第一条 feature_video 的声音。
options.callback_urlstring否任务状态变化时的回调地址。
options.external_task_idstring否自定义任务 ID，不覆盖 data.id。同一 API Key 下必须唯一。用 GET /kling/tasks?external_task_ids= 查询。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。传入 false 也会按 false 提交，不会省掉。不支持自定义水印。

提示词用 @id 引用素材，并写明每项用途。可灵说明：文生视频、图生视频、Omni、Flash。

字段类型必填说明
contentsarray是至少 1 张关键帧，可附提示词。图片最多 10 张。
contents[].typestring是prompt、first_frame、middle_frame、last_frame。
contents[].textstring条件type=prompt 时必填。字符限制与文生视频 prompt 相同。

contents[].textstring条件提示词项必填。字符限制与文生视频 prompt 相同。写明各素材用途，以及要修改和保留的内容。

素材限制

素材数量规格
图片最多 10 张JPG、JPEG、PNG。单张不超过 30 MB，宽高均不小于 300px，宽高比 2:5 至 5:2。
参考视频最多 5 个；base_video 最多 1 个；与视频角色元素合计最多 5 个MP4、MOV，单个不超过 300 MB。每个及合计时长：4.0 为 3–30 秒，Flash 为 3–20 秒（含视频角色元素）。帧率 24–60 fps。宽、高各 700–4553px，总像素不超过 8,294,400，宽高比 2:5 至 5:2。
元素 / 声音元素最多 7 个，其中视频角色元素最多 3 个；声音最多 3 个图片、视频、元素、声音总数最多 15 个。
校验本接口先校验字段、枚举、ID 和数量。文件大小、分辨率、输入视频时长和元素类型等媒体属性由可灵校验。

响应字段说明
code成功为 0。
data[].id任务 ID，与创建响应的 data.id 相同。
data[].statussubmitted、processing、succeeded、failed。
data[].message失败时为失败原因。
data[].outputs成功后的结果。视频项含 type、id、url、watermark_url、duration。duration 是成片时长，单位秒。结果链接通常保留 30 天，请及时保存。
data[].usage.output_duration计费用的输出时长，单位秒。有 settings.duration 时用该值；否则用提示词中的时长；都没有时，Omni 用 base_video 取整后的时长，再否则为 10 秒。计算费用用这个字段，不要用 outputs[].duration。
data[].usage.input_duration输入视频总时长，保留两位小数的字符串。只在有视频输入且任务结束后返回，含 feature_video、base_video 和视频角色主体。时长按归一化后的视频计算，可能和原文件略有差别。
data[].billing扣费明细，可有多条。字段：charge_type（cash 或 unit）、cash_type、amount、currency、package_type、list_price。按上方价格表扣费。
data[].external_id自定义任务 ID。
data[].create_time / update_time毫秒时间戳。

游标查询的 data 是对象：任务在 data.result，并带 count、next_cursor、has_more。filters.status 可用 submitted、processing、succeeded、failed；filters.product_type 中，视频任务为 video。
