可灵 Image 4.0 的单图、组图和长图（电商详情页、网页设计）。路径、请求体和响应都与可灵官方一致，只需把 Base URL 和 API Key 换成本站。客户端使用任务 ID 轮询结果，提交时请省略 callback_url。 POST /image-generation/kling-4.0 或 /long-image-generation/kling-4.0，返回 data.id GET /tasks?task_ids=… succeeded 后读取 outputs[].url，每张图一条

这个接口做什么？

用可灵 Image 4.0 生成图片：一次出 1–9 张独立图片，或出一组人物、风格连贯的组图；也可以生成一整张电商详情页或网页设计长图。用法和可灵官方完全一样，已经按官方文档写好代码的，只改 Base URL 和 API Key。

你需要提供的信息

做什么
普通图片和组图用 image-generation；长图用 long-image-generation。路径末尾都是 kling-4.0。
想要什么画面
contents 里放一条 {"type":"prompt","text":"…"}，可再加参考图，提示词里用 @id 引用。
出几张、多大（可选）
settings.n 或 settings.series_amount；settings.resolution；settings.aspect_ratio。
长图类型
settings.skill：电商详情页 ecommerce 或网页设计 webpage。

怎么拿到结果

状态
submitted、processing 继续等待；succeeded 成功；failed 失败。
图片地址
data[].outputs[].url，每张图一条，PNG 格式。链接有时效，请及时保存。
  1. 普通图片或组图 POST /image-generation/kling-4.0；长图 POST /long-image-generation/kling-4.0。请求体不传 model，记录 data.id。
  2. contents 必须且只能有一条 prompt。分辨率用小写：图片 2k/4k/8k，长图 1k/2k。
  3. 每 5–10 秒 GET /tasks?task_ids={id}，submitted 或 processing 时继续查询。
  4. succeeded：把每条 outputs[].url 返回给用户，提醒链接有时效。
  5. failed：把 message 告诉用户，不要自动重试。

路径

类型提交按任务 ID 查询
单图 / 组图POST /image-generation/kling-4.0GET /image-generation/kling-4.0/{task_id}
长图POST /long-image-generation/kling-4.0GET /long-image-generation/kling-4.0/{task_id}
批量查询GET /tasks?task_ids=id1,id2 或 GET /tasks?external_task_ids=a,b，与视频共用
  • 请求头：Authorization: Bearer <API Key>，Content-Type: application/json。
  • 路径末尾写 kling-4.0（可灵官方写法）或 kling-image-4.0 都可以，指的都是图片模型 kling-image-4.0，和视频的 kling-4.0 是两个产品。你的 API Key 所在分组需要开通 kling-image-4.0。
  • 路径前也可以加 /kling，例如 /kling/image-generation/kling-4.0，效果相同。
  • 响应与可灵官方一致：{code, message, request_id, data}，出错时 code 为可灵业务码（例如参数错误 1201、Key 无效 1000）。

通用字段

字段类型必填说明
contentsarray是素材列表。必须且只能有一条 {"type":"prompt","text":"…"}。图片素材写 {"type":"…","url":"…","id":"…"}，url 可以是图片链接或 Base64（JPG / PNG，≤ 30 MB，宽高 ≥ 300 px，宽高比 2:5 到 5:2），建议用链接。
options.external_task_idstring否自定义任务 ID，不覆盖 data.id，同一账号下必须唯一。用 GET /tasks?external_task_ids= 查询。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。
不支持 options.callback_url（传了会返回 400），请轮询查询接口。素材链接由可灵在中国大陆以外下载，需要公网可访问、无需登录。

错误响应 · 400

{
  "code": 1201,
  "message": "settings.resolution must be one of 2k, 4k, 8k",
  "request_id": "req_xxxxxxxxxx"
}
字段类型必填说明
contents[].typestring是prompt（一条，必填）；refer_image 参考图，最多 10 张。
settings.result_typestring否single（默认）生成独立图片；series 生成人物、风格连贯的组图。
settings.ninteger否single 时生成几张，1–9，默认 1。
settings.series_amountinteger / string否series 时的张数，2–10 或 "auto"（由可灵决定 2–10 张），默认 4。
settings.resolutionstring否2k（默认）、4k、8k，必须小写。
settings.aspect_ratiostring否auto（默认）、16:9、9:16、1:1、4:3、3:4、3:2、2:3、21:9。

可灵官方的参考主体（element）本站暂不支持，请用 refer_image 传参考图。

请求示例 · 参考一张图生成单图

curl https://api.o1key.com/image-generation/kling-4.0 \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {"type": "prompt", "text": "以 @dog 中的小狗为参考，生成一张三维动画风格的角色海报，暖色灯光，背景简洁。"},
      {"type": "refer_image", "url": "https://cdn.example.com/dog.png", "id": "dog"}
    ],
    "settings": {"result_type": "single", "n": 1, "resolution": "2k", "aspect_ratio": "1:1"}
  }'

请求示例 · 4 张 4K 组图

curl https://api.o1key.com/image-generation/kling-4.0 \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {"type": "prompt", "text": "以 @dog 为主角生成四张连贯的三维动画故事图：走进咖啡馆、在窗边落座、闻咖啡香、在门口告别。"},
      {"type": "refer_image", "url": "https://cdn.example.com/dog.png", "id": "dog"}
    ],
    "settings": {"result_type": "series", "series_amount": 4, "resolution": "4k", "aspect_ratio": "3:4"},
    "options": {"external_task_id": "my-order-0001"}
  }'

每个任务生成一张完整长图，不支持指定张数。

字段类型必填说明
settings.skillstring是ecommerce 电商详情页；webpage 网页设计。
contents[].typestring是prompt（一条，必填）。ecommerce：必须有 1–3 张 refer_image。webpage：可选一张 style_refer_image（参考视觉和排版风格）和一张 subject_refer_image（围绕这个主体设计），不能用 refer_image。不支持 element。
settings.lengthstring否仅 ecommerce：short（约 2–5 个模块）、medium（默认，6–10）、long（11–18）。
settings.resolutionstring否1k（默认）或 2k。

提示词长度：纯英文最多 166,000 字符，纯非英文最多 71,000 字符；混合输入须满足 E/166000 + N/71000 ≤ 1。长图生成通常比普通图片慢。

参数说明
task_ids任务 ID，逗号分隔，每次最多 50 个。
external_task_ids自定义任务 ID，逗号分隔。不能与 task_ids 同时使用。
字段说明
data任务数组。不存在或不属于你的任务不会出现在数组里（200 + 空数组）。
statussubmitted、processing、succeeded、failed。
outputs[]每张图一条，type 为 image，各有自己的 url，顺序与可灵一致。组图另有 group_id。没有 duration 和 usage。
message失败原因，例如内容审核未通过。
