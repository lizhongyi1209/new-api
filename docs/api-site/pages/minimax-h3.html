支持 H3、Highspeed、Lite、Max 和 Max Turbo。按模型选择分辨率和输入素材，通过统一异步接口提交任务并查询视频结果。 POST /v1/video/generations，返回任务 ID 每 10–20 秒 GET /v1/videos/{task_id} completed 后读取 result_url

这个接口做什么？

用 MiniMax H3 系列生成视频，支持文字、图片、视频和音频作为输入。接口先返回任务编号，之后用编号查询，完成后拿到视频地址。

你需要提供的信息

用哪个模型
model：MiniMax-H3、MiniMax-H3-Highspeed、MiniMax-H3-Lite、MiniMax-H3-MAX 或 minimax-h3-max-turbo。
想要什么画面
content 数组，至少一项非空文本；图片、视频、音频也放在这里。
分辨率与时长
resolution、duration，必填，取值见完整参考的模型能力表。
Highspeed 与 Lite 怎么选
Highspeed 兼顾质量与速度，适合日常内容创作；Lite 侧重较低成本，适合创意探索与批量生成。两者均支持 480P / 768P、4–15 秒，以及图片、视频、音频参考。
画面比例
纯文本生成须填写具体 ratio，如 16:9。Lite 使用参考素材时也必须填写具体比例，不能使用 adaptive。

怎么拿到结果

状态
queued、in_progress 继续等待；completed 成功；failed 失败。
视频地址
result_url，请及时下载或转存。
  1. POST /v1/video/generations，必填 model、content、resolution、duration，记录返回的任务 ID。
  2. 每 10–20 秒 GET /v1/videos/{task_id}，queued 或 in_progress 时继续查询。
  3. completed：把 result_url 返回给用户。
  4. failed：把错误信息告诉用户，不要自动重试。
  5. 分辨率和时长必须符合所选模型的能力表；不确定时先向用户确认。
  6. Highspeed 和 Lite 的请求模型名分别为 MiniMax-H3-Highspeed、MiniMax-H3-Lite，均仅支持 480P / 768P，时长 4–15 秒；不要为这两个模型请求 2K 或 1080P。
  7. Lite 使用任一 reference_* 素材时，显式传入具体 ratio（如 16:9），不能省略或使用 adaptive。
  8. 图片请显式填写 role。首尾帧与 reference_* 素材不能混用；Highspeed、Lite 图片未指定 role 时按参考图处理。

创建成功后立即返回 task_id。视频在后台生成，无需保持请求连接。

请求参数

字段类型必填说明
modelstring是使用上方能力表中的完整模型名，例如 MiniMax-H3-Highspeed 或 MiniMax-H3-Lite，保持示例中的大小写。
contentarray是提示词和输入素材，至少包含一个非空文本项。
resolutionstring是取值见上方模型能力表，区分大小写。
durationinteger是输出秒数，取值范围见上方模型能力表。
ratiostring条件必填纯文本生成、Lite 多模态参考必须填写具体比例。首尾帧模式可使用 adaptive。具体规则见下表。
callback_urlstring否任务状态回调地址。建议同时保留查询任务的兜底逻辑。

画面比例规则

固定比例可选 21:9、16:9、4:3、1:1、3:4、9:16。

输入场景ratio 规则
纯文本生成（全部模型）必填固定比例，不能为 adaptive。
首帧 / 尾帧 / 首尾帧（全部模型）可使用 adaptive，比例跟随输入图片。使用尾帧时请同时提供首帧。
H3、Highspeed 的多模态参考可省略或使用 adaptive，也可指定固定比例。
Lite 的多模态参考必填固定比例，例如 16:9；省略或使用 adaptive 会返回参数错误。

content 项

type数据字段role适用模型
texttext不填全部；提示词最多 7000 个字符
image_urlimage_url.urlfirst_frame / last_frame全部；请显式填写 role
image_urlimage_url.urlreference_imageH3、Highspeed、Lite
video_urlvideo_url.urlreference_videoH3、Highspeed、Lite
audio_urlaudio_url.urlreference_audioH3、Highspeed、Lite

建议所有图片都显式填写 role，以准确选择输入模式。Highspeed、Lite 的图片省略 role 时按 reference_image 处理；H3、H3 Max、H3 Max Turbo 则按 first_frame 处理。

素材限制

素材格式与大小其他限制
图片JPG、JPEG、PNG、WEBP、HEIC、HEIF；单张不超过 30MB宽高 256-5760px，宽高比 0.4-2.5
参考视频MP4、MOV；单个不超过 50MB单段 2-15 秒，总时长不超过 15 秒，23.976-60fps
参考音频WAV、MP3；单个不超过 15MB单段 2-15 秒，总时长不超过 15 秒
  • 请求体不超过 64MB。素材可使用公网 URL 或对应格式的 Base64 Data URI，大文件建议使用 URL。
  • H3、Highspeed、Lite 最多包含 9 张参考图、3 个参考视频、3 个参考音频，全部参考素材合计不超过 12 个。
  • first_frame/last_frame 不能与任一 reference_* 素材混用。

计费说明

H3、Highspeed 和 Lite 按输出视频秒数计费；参考视频另按输入秒数计费；参考音频免费；每次请求前 5 张输入图片免费，第 6 张起按张计费。不同模型、分辨率的单价可能不同，请以账户适用价格为准。H3 Max 和 H3 Max Turbo 仅按输出视频秒数计费。

创建任务时会预扣额度，完成后按实际用量结算；包含参考视频的任务可能在完成后补扣输入视频费用。任务失败会退回已预扣额度，最终费用以消费记录为准。

创建响应

{
  "id": "task_h3_xxxxxxxxxx",
  "task_id": "task_h3_xxxxxxxxxx",
  "object": "video",
  "model": "MiniMax-H3",
  "status": "queued",
  "progress": 0,
  "created_at": 1786350000
}

使用创建接口返回的 task_id 查询。建议每 10-20 秒轮询一次，直到任务变为 completed 或 failed。

状态处理方式
queued / in_progress任务排队或生成中，继续轮询。
completed读取 result_url 并及时下载或转存。
failed读取 error.code 和 error.message。
unknown任务刚创建时可能短暂出现，按 queued 处理。

响应字段

响应字段说明
id / task_id任务 ID，两个字段值相同。
status / progress任务状态和进度；进度仅用于展示，不代表精确剩余时间。
result_url任务完成后的视频地址。
seconds / size实际输出时长和分辨率。
metadata.usage实际输入与输出用量，包括视频秒数、音频秒数和图片数量。
error失败信息，仅在任务失败时返回。
处理中可能没有 result_url、metadata 或完整用量信息，仅在 completed 后读取结果地址。
