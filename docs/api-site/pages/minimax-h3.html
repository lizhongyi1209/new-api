通过统一异步接口创建任务，并使用任务 ID 查询生成结果。 POST /v1/video/generations，返回任务 ID 每 10–20 秒 GET /v1/videos/{task_id} completed 后读取 result_url

这个接口做什么？

用 MiniMax H3 系列生成视频，支持文字、图片、视频和音频作为输入。接口先返回任务编号，之后用编号查询，完成后拿到视频地址。

你需要提供的信息

用哪个模型
model：MiniMax-H3、MiniMax-H3-MAX 或 minimax-h3-max-turbo。
想要什么画面
content 数组，至少一项非空文本；图片、视频、音频也放在这里。
分辨率与时长
resolution、duration，必填，取值见完整参考的模型能力表。

怎么拿到结果

状态
queued、in_progress 继续等待；completed 成功；failed 失败。
视频地址
result_url，请及时下载或转存。
  1. POST /v1/video/generations，必填 model、content、resolution、duration，记录返回的任务 ID。
  2. 每 10–20 秒 GET /v1/videos/{task_id}，queued 或 in_progress 时继续查询。
  3. completed：把 result_url 返回给用户。
  4. failed：把错误信息告诉用户，不要自动重试。
  5. 分辨率和时长必须符合所选模型的能力表；不确定时先向用户确认。

创建成功后立即返回 task_id。视频在后台生成，无需保持请求连接。

模型能力

模型支持场景分辨率时长
MiniMax-H3文生视频、首帧/尾帧/首尾帧图生视频、图片/视频/音频多模态参考768P、2K4-15 秒
MiniMax-H3-MAX文生视频、首帧/尾帧/首尾帧图生视频480P、768P5-15 秒
minimax-h3-max-turbo文生视频、首帧/尾帧/首尾帧图生视频480P、768P、1080P5-15 秒
需要 2K 或多模态参考时请选择 MiniMax-H3；H3 Max 和 H3 Max Turbo 不支持 reference_* 素材。需要 1080P 时请选择 minimax-h3-max-turbo。

请求参数

字段类型必填说明
modelstring是MiniMax-H3、MiniMax-H3-MAX 或 minimax-h3-max-turbo。
contentarray是提示词和输入素材，至少包含一个非空文本项。
resolutionstring是取值见上方模型能力表，区分大小写。

callback_urlstring否任务状态回调地址。建议同时保留查询任务的兜底逻辑。

type数据字段role适用模型

素材限制

素材格式与大小其他限制
图片JPG、JPEG、PNG、WEBP、HEIC、HEIF；单张不超过 30MB宽高 256-5760px，宽高比 0.4-2.5
参考视频MP4、MOV；单个不超过 50MB单段 2-15 秒，总时长不超过 15 秒，23.976-60fps
参考音频WAV、MP3；单个不超过 15MB单段 2-15 秒，总时长不超过 15 秒
  • 请求体不超过 64MB。素材可使用公网 URL 或对应格式的 Base64 Data URI，大文件建议使用 URL。
  • H3 最多包含 9 张参考图、3 个参考视频、3 个参考音频，全部参考素材合计不超过 12 个。
  • first_frame/last_frame 不能与任一 reference_* 素材混用。

计费说明

H3 按输出视频秒数计费；参考视频按输入秒数计费；参考音频免费；参考图片前 5 张免费，超出部分按张计费。H3 Max 和 H3 Max Turbo 仅按输出视频秒数计费。创建任务时会预扣额度，完成后按实际用量结算，最终费用以消费记录为准。

创建响应

{
  "id": "task_h3_xxxxxxxxxx",
  "task_id": "task_h3_xxxxxxxxxx",
  "object": "video",
  "model": "MiniMax-H3",
  "status": "queued",
  "progress": 0,
  "created_at": 1786350000
}

使用创建接口返回的 task_id 查询。建议每 10-20 秒轮询一次，直到任务变为 completed 或 failed。

状态处理方式
queued / in_progress任务排队或生成中，继续轮询。
completed读取 result_url 并及时下载或转存。
failed读取 error.code 和 error.message。
unknown任务刚创建时可能短暂出现，按 queued 处理。

响应字段

响应字段说明
id / task_id任务 ID，两个字段值相同。
status / progress任务状态和进度；进度仅用于展示，不代表精确剩余时间。
result_url任务完成后的视频地址。
seconds / size实际输出时长和分辨率。
metadata.usage实际输入与输出用量，包括视频秒数、音频秒数和图片数量。
error失败信息，仅在任务失败时返回。
处理中可能没有 result_url、metadata 或完整用量信息，仅在 completed 后读取结果地址。
