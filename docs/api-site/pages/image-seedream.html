单图生成、参考图编辑、多图融合和图层拆分。 POST /async/v1/generateImage，返回 task_id GET /async/v1/tasks/{task_id} SUCCESS 后读取 data.images

这个接口做什么？

生成单张图片，或基于参考图编辑、融合多张图，还可以把一张图拆成多个图层。接口先返回任务编号，之后用编号查询，完成后拿到图片地址。

你需要提供的信息

用哪个模型
model：dola-seedream-5-0-pro-260628-ep 或 dola-seedream-5-5-261028-ep。
想要什么画面
prompt。
参考图（可选）
images，用于编辑和多图融合。
图层拆分（可选）
layer_decomposition，把图片拆成多个图层分别返回。

怎么拿到结果

查询
用 task_id 调 GET /async/v1/tasks/{task_id}。
状态
SUBMITTED、IN_PROGRESS 继续等待；SUCCESS 成功；FAILURE 失败。
图片地址
成功后读 data.images[].url；失败时读 error。
  1. POST /async/v1/generateImage，model 用 dola-seedream-5-0-pro-260628-ep 或 dola-seedream-5-5-261028-ep，记录返回的 task_id。
  2. 每 5 秒 GET /async/v1/tasks/{task_id}，SUBMITTED 或 IN_PROGRESS 时继续查询。
  3. SUCCESS：把 data.images[].url 返回给用户。
  4. FAILURE：把 error 中的信息告诉用户，不要自动重试。
  5. 缺少 model 或 prompt 时，先向用户确认，不要猜测。

请求参数

字段必填类型说明
model是stringdola-seedream-5-0-pro-260628-ep 或 dola-seedream-5-5-261028-ep。
prompt否*string图片生成、编辑或多图融合时必填；图层拆分时可省略，由模型自动识别待拆分元素。
images否string[]公网图片 URL 数组，最多 10 张。单张参考图也必须放入数组；图层拆分模式必须且只能传 1 张。
n否integer仅支持单图输出，省略或传 1。
size否string图片生成模式支持 1K、2K 或合法的 WIDTHxHEIGHT；图层拆分模式仅支持 auto、1K、1.5K、2K，省略时按 auto 处理。
output_format否stringpng 或 jpeg。
watermark否booleantrue 添加“AI 生成”水印，false 不添加。
layer_decomposition否boolean图层拆分开关，默认 false，仅 Seedream 5.0 Pro 支持。设为 true 时，将输入图拆解为 1 张底图和最多 16 个带透明通道的 PNG 图层。

图层拆分

规则说明
输入images 必须且只能包含 1 张待拆分图片。
输出data.images 返回 1 张底图和最多 16 个图层，按 z_index 表示图层顺序。
图层信息每项可包含 bounding_box、name 和 description；bounding_box.absolute 为绝对像素坐标，bounding_box.normalized 为 0–1000 归一化坐标。
失败处理任一图层生成失败时，整个任务返回 FAILURE，不返回部分结果。
数量上限提示词要求的图层数量超过上限时，超出部分可能不会返回。

计费

基础价格按火山引擎中国区官方价格及实际输出结算：图片生成模式不超过 261 万像素为 ¥0.30 / 张，超过 261 万像素为 ¥0.60 / 张；图层拆分模式按每张实际返回图片计费，底图计入数量，不超过 261 万像素为 ¥0.15 / 张，超过 261 万像素为 ¥0.30 / 张。图片生成模式首张参考图免费，从第 2 张起每张增加 ¥0.02。最终价格乘以调用密钥所属分组的倍率。

Seedream 5.5 按实际输出结算：不超过 261 万像素为 ¥0.14 / 张，超过 261 万像素为 ¥0.245 / 张。每张参考图增加 ¥0.056（从第 1 张起计）。最终价格同样乘以分组倍率。
