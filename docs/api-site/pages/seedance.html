提交视频任务，保存任务 ID，再查询结果。参考素材可直接传 URL，需要复用时再预上传。 POST /v1/video/generations，返回 task_... 每 5–10 秒 GET /v1/video/generations/{task_id} completed 后读取 result_url

这个接口做什么？

用 Seedance 生成视频：可以只写文字，也可以加参考图、参考视频和音频。参考素材直接传公网 URL 即可，需要反复使用同一素材时再预先上传成素材句柄。接口先返回任务编号，之后用编号查询。

你需要提供的信息

用哪个模型
model，例如 doubao-seedance-2-0，可选列表见完整参考。
想要什么画面
content 数组，至少一项非空 text，第一条文本作为提示词；素材也放在这里。
时长、分辨率、比例（可选）
duration、resolution、ratio。

怎么拿到结果

状态
queued、in_progress 继续等待；completed 成功；failed 失败。
视频地址
result_url（同 metadata.url）。链接通常 24 小时有效，请及时转存。
  1. POST /v1/video/generations，content 至少包含一项非空 text，记录返回的本站任务 ID（task_...）。
  2. 每 5–10 秒 GET /v1/video/generations/{task_id}。in_progress 包括素材准备，继续查询即可。
  3. completed：把 result_url 返回给用户，提醒链接约 24 小时有效。
  4. failed：把 error.message 告诉用户，不要自动重试。
  5. 创建请求超时时先查询已有任务，避免重复提交和重复计费。缺少 model 或提示词时，先向用户确认。
接入步骤：使用本站 API Key 提交请求 → 保存响应中的 id / task_id → 调用查询接口，直到 completed 或 failed。

下表适用于 Doubao MAX 与 Dreamina MAX。新接入请使用简写模型名；实际可用模型以本站 GET /v1/models 返回为准。

完成通知与任务关联

callback_url 会原样转发，上游直接向该地址 POST 状态通知。回调体是 {"task": {...}}，其中 task.id 是上游任务标识；本站查询接口返回 task_... 和 object: "video"。

建议在回调 URL 带上自己的业务 ID（如 ?job_id=123），提交成功后保存业务 ID 与本站 task_id 的关联。收到通知后用本站任务 ID 查询确认结果；保留轮询作为兜底。

使用创建响应中的本站任务 ID（task_...）查询进度和结果，携带同一个本站 API Key。

状态说明
queued已提交，等待生成
in_progress素材准备或视频生成中
completed生成完成，从结果字段取下载地址
failed生成失败，读取 error.message

结果读取

字段用途
result_url / metadata.url视频下载地址，两者兼容；完整输出列表在 metadata.outputs
metadata.last_frame_url尾帧 PNG 下载地址，仅当请求开启 return_last_frame 时返回
metadata.usage.completion_tokens上游实际视频 token 用量；最终费用以本站消费记录为准
metadata.upstream_status素材准备时为 preparing；本站对外状态仍为 in_progress
metadata.prep素材准备进度：total 总数、active 已就绪、failed 失败、attempt 尝试轮次；失败时可能带 failedRefs
error.message失败原因，素材错误会指出 @Image1、@Video1 等编号

建议每 5–10 秒查询一次，直到进入终态。素材准备属于正常处理过程，收到 in_progress 后继续查询即可。

默认透传的上游视频 / 尾帧签名链接通常有效 24 小时，无需鉴权即可下载；需要长期保存时请及时转存。

通过公开 URL 创建可复用素材。仅使用一次的素材可直接在视频请求中传入 URL。

字段必填类型说明
type是stringdreamina、doubao 或 hc（兼容旧名）；须与视频模型对应
url是string公开素材地址；HC 要求 HTTPS，Dreamina 与 Doubao 接受 HTTP(S)。asset:// 和 data: 会被拒绝
name否string素材名称
asset_type否stringimage、video 或 audio；默认 image
model否string用于选择渠道，并在 Dreamina / Doubao 上转发给上游。Dreamina 可省略；如填写，使用本站公开名（推荐简写如 dreamina-seedance-2-0-mini，兼容 -hc 旧名）或上游 dreamina-*-max。Doubao 建议省略；如填写，使用 doubao-seedance-2-0 或 doubao-seedance-2-0-260128-max

type: "dreamina" 转发到 POST /v2/sd-max/assets，type: "doubao" 转发到 POST /v2/db-sd-max/assets。这两条上游路径也可以直接调用，请求体字段为 URL、AssetType、Name、Model，响应原样返回 Id、Ref、Status。上传是 POST 到不带 id 的路径。

国外 Dreamina 预上传流程

  1. POST /v1/seedance/assets：type 为 dreamina，model 为即将用于生成的简写（示例用 dreamina-seedance-2-0-mini），asset_type 为 image，url 为公网图片。
  2. GET /v1/seedance/assets/{data.Id}?type=dreamina：每 1–2 秒查询，直到 data.Status 为 Active。记下 data.Ref（形如 asset://...）。
  3. POST /v1/video/generations：model 仍用同一个简写，把 Ref 填进 content[].image_url.url，role 为 reference_image。示例为 resolution: "480p"、duration: 4、generate_audio: false。
  4. GET /v1/video/generations/{id}：使用创建响应里的本站 task_...，直到 status 为 completed 或 failed。句柄已是 Active 时，任务通常直接是 queued，而不是素材准备中的 in_progress。

右侧示例里的素材 ID、任务 ID 和图片地址都是占位示例，不是线上记录。只使用一次的素材不必预上传，直接把公网 URL 放进视频请求即可。上传素材免费，句柄有效期 7 天。

句柄只对创建它时实际选中的那把上游密钥及其组织有效。Dreamina 与豆包不能混用。同一家族若有多把密钥或多个组织，只传 type 会在当前分组里选优先级最高的匹配渠道；之后生成若落到另一把密钥，句柄不能用。预上传请带上与生成请求相同的公开模型名，使两边都在提供该模型的渠道中选择。即便如此，同一模型仍可能对应多把密钥，句柄不能假定在同家族或同模型的其他密钥上可用。
