本文档面向接入方技术团队，说明如何调用图像与视频生成接口。所有接口共用一套 Bearer 鉴权：先上传参考素材取得公网地址，再提交生成任务，最后按任务 ID 轮询结果。

基本信息

入口Base URL说明
主地址 推荐https://api.o1key.com文档示例均使用此地址，适合长连接
Cloudflare 备用https://cf-api.o1key.com单次连接最长 100 秒
项目说明
认证方式请求头 Authorization: Bearer <API Key>，所有接口相同
数据格式JSON，UTF-8 编码。素材上传接口使用 multipart/form-data
素材地址参考图、视频、音频需为公网可直接下载的 URL。本地文件先用素材上传换取 URL

接口一览

任务流程

1上传素材
本地文件先换取公网 URL，线上素材可直接使用。
2提交任务
选择模型与参数，立即返回任务 ID。
3轮询结果
用任务 ID 查询，直到成功或失败。各接口的状态名和建议间隔见对应页面。
