把本地图片、音频、视频或文档上传，换取生成接口可以引用的公网 URL。同步返回，无需轮询。 multipart/form-data，字段 file，每次 1 个 POST /v1/o1key/uploads 把返回的 url 填进生成接口的素材字段

这个接口做什么？

生成接口只接受公网可下载的素材地址。手里只有本地文件时，先用这个接口上传，拿到 URL 后再提交生成任务。

你需要提供的信息

文件
file，每次 1 个文件，最大 20 MiB。多个文件请分别上传。
格式
图片 png / jpg / jpeg / webp，音频 mp3 / wav / m4a，视频 mp4 / mov，文档 pdf / txt / md。

怎么拿到结果

返回
接口直接返回 url，上传后 24 小时内有效，到期时间见 expires_at。
  1. 用 multipart/form-data POST /v1/o1key/uploads，字段名 file，一次一个文件。
  2. 从响应读取 url，填入生成接口的素材字段；注意 expires_at。
  3. 400 表示文件无效、格式不支持或传了多个文件；413 表示超过大小限制。把原因告诉用户，不要自动重试。

Authorization: Bearer <API Key> · multipart/form-data

参数：file（必填，每次 1 个文件，最大 20 MiB）。多个文件请分别上传。

返回的 url 可直接用作各生成接口的参考素材，上传后 24 小时内有效，到期时间见 expires_at。

支持的文件格式

类型扩展名
图片png、jpg、jpeg、webp
音频mp3、wav、m4a
视频mp4、mov
文档pdf、txt、md

常见错误：400 文件无效、格式不支持或传入多个文件 · 401 鉴权失败 · 413 超过大小限制

请求

curl -X POST "$BASE_URL/v1/o1key/uploads" \
  -H "Authorization: Bearer $API_KEY" \
  -F "file=@./reference.png"

成功响应

{
  "url": "https://upload.o1key.com/tmp/input/7f46d5e8-9bf6-45c4-9a3a-87dbd5138dd1.png",
  "filename": "reference.png",
  "content_type": "image/png",
  "size": 11630,
  "expires_at": 1787495062
}

错误响应（HTTP 400 示例）

{
  "error": "unsupported attachment type"
}
