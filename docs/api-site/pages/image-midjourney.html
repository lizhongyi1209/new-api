这个接口做什么？

用 Midjourney 生成图片。画面比例、画质、风格参考等设置直接写在提示词末尾，沿用 Midjourney 原生写法。标准模式每次返回 4 张图，单次通常需要 60–170 秒。

你需要提供的信息

用哪个模型
model，固定 mj-v8.2。
想要什么画面
prompt，参数写在末尾，例如 A cat --ar 16:9 --q 2。
参考图（可选）
images，或把公网图片 URL 写进提示词。

怎么拿到结果

查询
用 task_id 调 GET /async/v1/tasks/{task_id}。
状态
SUBMITTED、IN_PROGRESS 继续等待；SUCCESS 成功；FAILURE 失败。
图片地址
成功后读 data.images[].url；失败时读 error。
  1. POST /async/v1/generateImage，model 用 mj-v8.2，比例等参数写在 prompt 末尾，记录返回的 task_id。
  2. 每 5–10 秒 GET /async/v1/tasks/{task_id}，SUBMITTED 或 IN_PROGRESS 时继续查询。
  3. SUCCESS：把 data.images[].url 返回给用户。
  4. FAILURE：把 error 中的信息告诉用户，不要自动重试。
  5. 缺少 model 或 prompt 时，先向用户确认，不要猜测。
写法与其它生图模型不同：Midjourney 的画幅、画质、高清档等设置全部写在 prompt 末尾，沿用 Midjourney 原生参数语法。

模型名称

模型名称版本能力
mj-v8.2v8.2文生图、单图参考、Prompt 多内容参考、风格参考（--sref）

请求参数

字段必填类型说明
model是string固定使用 mj-v8.2。
prompt是string提示词。画幅、画质、参考图 URL、--sref 等设置都写在这里，例如 A cat --ar 16:9 --q 2。多张内容参考请把公网 URL 写在提示词开头。
images否string[]参考图 URL 数组，元素为字符串（不是对象）。最多 1 张；传两张及以上会返回 400。需要多张内容参考时，把 URL 写进 prompt 开头，不要塞进本字段。

提示词参数

以下参数直接写在 prompt 末尾，按 Midjourney 原生语法生效：

参数作用取值说明
--ar画面比例1:1、16:9、9:16、4:5、3:2、2:3、21:9 等默认 1:1。控制比例，不承诺精确像素。
--q渲染质量档位1、2、3、4v8.2 支持全部四档。
--hd高清档输出开关开启后长边翻倍到 2048 左右。
--iw内容参考权重0–3，默认 1数值越高越贴合内容参考。对 images 单图，以及写在 prompt 开头的内容参考 URL 均有效。
--raw原生模式开关弱化默认美化滤镜，画面更写实。
--s / --stylize风格化强度0–1000，默认 250越高越艺术化。
--c / --chaos四张差异度0–100越高，四张候选图差异越大。
--seed随机种子整数相同种子可复现同一结果。
--no排除元素关键词例如 --no people。
--sref / --sw风格参考图与权重URL；0–1000，默认 100迁移参考图的色彩、笔触、氛围。
--tile无缝平铺开关输出可重复拼接的纹理。
--weird超现实怪异度0–3000画面越离奇。
--exp动态影调增强0–100增强画面冲击力；例如 --exp 50。
--draft草图模式开关更快的草图输出。v8 规则与早期版本不同：不保证返回 4 张，现网实测可能返回多张约 512 边长的草稿图。
多参考图怎么写：images 只能传 1 张字符串 URL。多张内容参考请把公网 URL 写在 prompt 开头，再用 --iw 控强度；风格参考用 --sref URL --sw N。内容参考与 --sref 可以组合使用。
已移除的参数：--stop、:: 分段加权、--cref、--oref 在 v8.1 及之后版本已不支持，写入提示词会被上游拒绝或忽略，请勿对外宣称支持。

输出尺寸

输出尺寸由 --ar 和档位共同决定。标准档的常见比例：

--ar标准档输出加 --hd
1:11024 × 10242048 × 2048
16:91456 × 8162944 × 1648
9:16816 × 14561648 × 2944
4:5960 × 1200约 1920 × 2400
3:21344 × 896约 2688 × 1792
4:31232 × 928约 2464 × 1856

未列出的比例同样按 --ar 输出，长边像素与同档位接近；加 --hd 后长边约为标准档的两倍。

关于 4K：v8.2 最高输出 2K，--hd 已是上限，无法输出 4K。

图生图与多参考

项目规则
images 数量最多 1 张字符串 URL；传两张及以上返回 400。
格式JPEG、PNG、WebP
文件大小不超过 7MB
传入方式公网可访问的 http(s) URL，或 data:image/...;base64, 形式的数据。
单图常用写法例如 Replace the outfit with a black knit cardigan --ar 4:5 --iw 2 --raw，并把 URL 放进 images。
多内容参考把多张公网 URL 写在 prompt 开头，例如 https://a.jpg https://b.jpg a fashion editorial --iw 1.5。
风格参考在 prompt 中写 --sref https://style.jpg --sw 80；可与内容参考组合。

计费

Midjourney 按次计费，不按张计费：标准模式一次任务返回 4 张图，只扣一次费用；使用 --draft 时出图数量可能更多、边长更小，仍按次计费。档位由实际输出分辨率决定。

档位触发方式输出
标准档默认长边约 1024
高清档提示词加 --hd长边约 2048
预扣与结算：提交时按高清档预扣，任务完成后按实际档位结算，差额自动退回。余额不足高清档时请求会被直接拒绝。最终价格乘以调用密钥所属分组的倍率。
