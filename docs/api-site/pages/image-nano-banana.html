原生 Gemini 图片生成、参考图编辑和多图融合。 POST /async/v1/generateImage，返回 task_id GET /async/v1/tasks/{task_id} SUCCESS 后读取 data.images

这个接口做什么？

用 Gemini 原生图片模型生成图片，也可以传一张或多张参考图做编辑和融合。接口先返回任务编号，之后用编号查询，完成后拿到图片地址。

你需要提供的信息

用哪个模型
model，例如 gemini-3.1-flash-image，可选列表见完整参考。
想要什么画面
prompt，写清主体、场景和风格。
参考图（可选）
images，多张图时可做融合。
尺寸与比例（可选）
size、aspect_ratio。

怎么拿到结果

查询
用 task_id 调 GET /async/v1/tasks/{task_id}。
状态
SUBMITTED、IN_PROGRESS 继续等待；SUCCESS 成功；FAILURE 失败。
图片地址
成功后读 data.images[].url；失败时读 error。
  1. POST /async/v1/generateImage，model 用用户指定的完整模型名，记录返回的 task_id。
  2. 每 5 秒 GET /async/v1/tasks/{task_id}，SUBMITTED 或 IN_PROGRESS 时继续查询。
  3. SUCCESS：把 data.images[].url 返回给用户。
  4. FAILURE：把 error 中的信息告诉用户，不要自动重试。
  5. 缺少 model 或 prompt 时，先向用户确认，不要猜测。

请求参数

字段必填类型说明
model是string使用上表中的完整模型名称。
prompt是string图片生成或编辑指令。
images否array参考图数组。单张参考图也必须放入数组，不要使用 image。
size否string1K、2K 或 4K，必须使用大写 K。默认 1K。
aspect_ratio否string输出宽高比，支持范围见下表。
thinking_level否stringGemini Nano Banana 2.1 系列支持 medium（中等）；Gemini 3.1 Flash Image 支持 minimal 或 high。
include_thoughts否boolean是否请求返回思考内容。任务查询结果仅返回图片。
response_modalities否string[]["IMAGE"] 或 ["TEXT","IMAGE"]。不要仅传 ["TEXT"]。

省略宽高比：有参考图时优先沿用输入比例，纯文生图通常使用 1:1。

参考图格式

格式写法说明
fileData{"fileData":{"mimeType":"image/jpeg","fileUri":"https://..."}}公网 HTTP(S) 图片地址。
inlineData{"inlineData":{"mimeType":"image/png","data":"..."}}不含 Data URI 前缀的 Base64。
兼容字符串https://... 或 Data URI已有客户端可继续使用，新接入建议显式声明格式。
请求大小：使用 inlineData 时，最终 Gemini JSON 请求体不得超过 20MiB。URL 必须保持公网可访问，直至任务完成。

请求示例

curl -X POST https://api.o1key.com/async/v1/generateImage \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-nano-banana-2.1-sp",
    "prompt": "生成一张 16:9 的极简科技产品海报",
    "size": "2K",
    "aspect_ratio": "16:9",
    "response_modalities": ["IMAGE"]
  }'
curl -X POST https://api.o1key.com/async/v1/generateImage \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.1-flash-image-c-sp",
    "prompt": "保留人物主体，参考第二张图的色彩和构图",
    "images": [
      {"fileData":{"mimeType":"image/png","fileUri":"https://upload.o1key.com/uploads/subject.png"}},
      {"fileData":{"mimeType":"image/png","fileUri":"https://upload.o1key.com/uploads/style.png"}}
    ],
    "size": "2K",
    "aspect_ratio": "16:9",
    "thinking_level": "high",
    "response_modalities": ["IMAGE"]
  }'

提交成功 200

{
  "task_id": "task_xxxxxxxxxxxxxxxx",
  "status": "SUBMITTED"
}

提交失败 400

{
  "error": {
    "message": "image 参数已废弃，请统一使用 images 字段；单张图也传入 images 数组",
    "type": "invalid_request_error"
  }
}

使用提交响应的 task_id 查询。SUBMITTED、IN_PROGRESS 表示继续等待；SUCCESS 读取 data.images，FAILURE 读取 error。

请求示例

curl https://api.o1key.com/async/v1/tasks/task_xxxxxxxxxxxxxxxx \
  -H "Authorization: Bearer $API_KEY"

生成成功 200

{
  "task_id": "task_xxxxxxxxxxxxxxxx",
  "status": "SUCCESS",
  "progress": "100%",
  "data": {
    "model": "gemini-nano-banana-2.1-sp",
    "created": 1786350000,
    "images": [
      {
        "url": "https://assetcache.o1key.com/images/example.png",
        "mime_type": "image/png"
      }
    ]
  }
}

生成失败 200

{
  "task_id": "task_xxxxxxxxxxxxxxxx",
  "status": "FAILURE",
  "progress": "100%",
  "error": "上游未返回图片数据"
}
