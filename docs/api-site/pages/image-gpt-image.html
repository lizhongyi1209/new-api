图片生成、透明背景输出和参考图编辑。 POST /async/v1/generateImage，返回 task_id GET /async/v1/tasks/{task_id} SUCCESS 后读取 data.images

这个接口做什么？

用一段文字生成图片，或者上传参考图让模型按你的要求修改。支持透明背景输出。图片需要一点时间生成，接口先返回任务编号，之后用编号查询，完成后拿到图片地址。

你需要提供的信息

用哪个模型
model，填完整模型名，例如 gpt-image-2，可选列表见完整参考。
想要什么画面
prompt，描述越具体，效果越接近预期。
参考图（可选）
images，传图片 URL 或 Base64，即为图片编辑。
尺寸与画质（可选）
size、quality，不传按默认值。

怎么拿到结果

查询
用 task_id 调 GET /async/v1/tasks/{task_id}。
状态
SUBMITTED、IN_PROGRESS 继续等待；SUCCESS 成功；FAILURE 失败。
图片地址
成功后读 data.images[].url；失败时读 error。
  1. POST /async/v1/generateImage，model 用用户指定的完整模型名，记录返回的 task_id。
  2. 每 5 秒 GET /async/v1/tasks/{task_id}，SUBMITTED 或 IN_PROGRESS 时继续查询。
  3. SUCCESS：把 data.images[].url 返回给用户。
  4. FAILURE：把 error 中的信息告诉用户，不要自动重试。
  5. 缺少 model 或 prompt 时，先向用户确认，不要猜测。

请求参数

字段必填类型说明
model是string使用上表中的完整模型名称。
prompt是string图片生成或编辑指令。
images否array参考图数组。支持 URL、Data URI、原始 Base64、fileData 和 inlineData。第一张是编辑目标。
markup否object2.5+ 标注图编辑。传 {"image_url": "..."}，与 images 等宽等高、透明底，标注层不叠加在原图上。与 prompt 一起说明「改什么」和「保留什么」。
mask否object蒙版局部重绘。传 {"image_url": "..."}，需带 alpha 通道；与 markup 互斥。蒙版仅作用于第一张参考图。
n否integer生成图片数量，1–128，默认 1。
size否stringauto 或 WIDTHxHEIGHT；常用尺寸见下表。
quality否string通用：low、medium、high、auto；2.5 / 2.6 额外支持 xhigh、max。
complexity否string仅 2.6：low、medium、high（默认 high）。控制渲染前的规划强度，越高越慢、改动幅度越大。
background否stringauto、transparent 或 opaque。透明背景要求 PNG 或 WebP。
output_format否stringpng（默认）、jpeg、webp；仅 2.6 额外支持 svg（仅生成）和 gif（生成与编辑）。
output_compression否integer0–100，仅对 jpeg / webp 生效。SVG 与 GIF 不支持。
partial_images否integer0–3，渐进预览帧数，每帧额外计费。SVG 与 GIF 不支持。
frame_count否integer仅 GIF：2–64 帧，默认 9。
frame_duration_ms否integer仅 GIF：每帧 20–2000 毫秒，默认 200，按 10ms 取整。
input_fidelity否string2.5 / 2.6 可传。GPT Image 2 必须省略，该系列始终高保真处理输入图。
moderation否stringauto 或 low。

常用尺寸

分辨率正方形横版竖版
自动auto
1K1024x10241536x1024、1360x1024、1824x10241024x1536、1024x1360、1024x1824
2K2048x20483072x2048、2736x2048、3648x20482048x3072、2048x2736、2048x3648
4K2880x28803504x2336、3264x2448、3840x21602336x3504、2448x3264、2160x3840
自定义尺寸：使用小写 x；宽高均须为 16 的倍数，比例介于 1:3 与 3:1，单边不超过 3840 像素，总像素为 655,360–8,294,400。超出范围会在提交阶段直接返回 400。
SVG / GIF 限制：仅 2.6 支持。SVG 只用于纯生成（对应 /v1/images/generations），编辑请求不能输出 SVG，也不能把 SVG 当作参考图。GIF 在生成和编辑中都可用；用静帧引导动画时把参考图放进 images（走编辑）。frame_count 与 frame_duration_ms 在两条路径上都生效。SVG 要求 n 为 1。两者都不支持流式、partial_images 与 output_compression。

9 帧 × 200ms ≈ 1.8 秒循环。带参考静帧时把图片放进 images，请求按编辑处理；GIF 在编辑中同样可用。

使用提交响应的 task_id 查询。SUBMITTED、IN_PROGRESS 表示继续等待；SUCCESS 读取 data.images，FAILURE 读取 error。

请求示例

  -H "Authorization: Bearer $API_KEY"
