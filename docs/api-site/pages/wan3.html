文生视频、首帧/首尾帧生视频、参考生视频和视频编辑。通过统一异步接口创建任务，并使用任务 ID 查询结果。 POST /v1/video/generations，返回 task_id 每 15 秒左右 GET /v1/video/generations/{task_id} completed 后读取 result_url

这个接口做什么？

用万相 3.0 生成视频：文生视频、首帧或首尾帧生视频、参考图 / 视频 / 音频生视频，也可以编辑一段已有视频。最长 30 秒。接口先返回任务编号，之后用编号查询。

你需要提供的信息

用哪个模型
model：wan3.0-video（标准）或 wan3.0-video-prime（更快）。
想要什么画面
prompt，必填。用「图1」「视频1」引用素材。
分辨率（建议填）
resolution：480p、720p、1080p。不传按 1080p 生成和计费。
时长（可选）
duration，2–30 秒，不传为 5 秒。
素材（可选）
image 作为首帧；更多素材放进 metadata.input.media。

怎么拿到结果

状态
queued、in_progress 继续等待；completed 成功；failed 失败。
视频地址
result_url（同 metadata.url），是限时链接，请及时下载转存。
  1. POST /v1/video/generations，model 为 wan3.0-video 或 wan3.0-video-prime，prompt 必填，记录返回的 task_id。
  2. 显式传 resolution，不传会按 1080p 生成和计费。
  3. 每 15 秒左右 GET /v1/video/generations/{task_id}，queued 或 in_progress 时继续查询。
  4. completed：把 result_url 返回给用户，提醒是限时链接。
  5. failed：把 error.code 和 error.message 告诉用户，不要自动重试。

创建成功后立即返回任务 ID，视频在后台生成，单次任务通常 1-5 分钟完成。

模型

模型说明
wan3.0-video标准版。
wan3.0-video-prime高速版，能力和参数与标准版完全相同，出片更快，单价更高。

请求参数

字段类型必填说明
modelstring是wan3.0-video 或 wan3.0-video-prime。
promptstring是提示词。只用素材时也请写一句描述。用「图1」「视频1」「音频1」引用参考素材，序号为该类型在 media 中出现的顺序。
resolutionstring否480p、720p 或 1080p。不传按 1080p 生成并计费，建议显式传。
durationinteger否输出秒数，2-30，不传为 5。智能时长用 metadata.parameters.duration: -1。
image / imagesstring / array否快捷写法：1 张图作为首帧，2 张图作为首帧和尾帧。传了 metadata.input.media 时以 media 为准。
metadata.input.mediaarray否素材数组，每项 {"type": "...", "url": "..."}，见下表。
metadata.parameters.ratiostring否adaptive、16:9、9:16、1:1、4:3、3:4、21:9。
metadata.parameters.durationinteger否2-30，或 -1 智能时长（按实际生成秒数计费）。传了以此为准。
metadata.parameters.audioboolean否是否带音轨，默认 true。
metadata.parameters.watermarkboolean否是否在右下角加「AI 生成」水印，默认 false。
metadata.parameters.seedinteger否随机种子。相同 seed 也不保证结果完全一致。
metadata.parameters.prompt_extendboolean否是否先智能改写提示词，默认 true。传 false 严格按原提示词生成，出片更快。

media 素材类型

type含义数量
first_frame视频第一帧最多 1 张
last_frame视频最后一帧，需与 first_frame 一起用最多 1 张
reference_image参考图最多 10 张
reference_video参考视频；也用于视频编辑、视频延长最多 5 段，总时长不超过 15 秒
reference_audio参考音频最多 5 段，总时长不超过 15 秒
  • 首尾帧与参考素材互斥：有 first_frame/last_frame 就不能再有 reference_*。参考图、参考视频、参考音频之间可以自由组合。
  • 带参考视频时，参考视频总时长 + 输出时长不超过 30 秒。
  • 素材 URL 必须是公网可直接下载的 HTTP/HTTPS 地址，不依赖登录态、Cookie 或 Referer。可先用素材上传得到 URL。
  • 图片：JPEG/JPG/PNG（不支持透明通道）/BMP/WEBP，单边 240-8000 像素，宽高比不超过 8:1，单张不超过 20MB。参考视频：MP4/MOV，单段 1-15 秒，帧率不低于 16fps，单个不超过 100MB。参考音频：WAV/MP3，单段 1-15 秒，单个不超过 15MB。

计费

按秒、按输出分辨率计费：计费秒数 = 输出视频秒数 + 参考视频秒数。提交时按上限预扣（智能时长按 30 秒；带参考视频时按参考视频 15 秒且合计不超过 30 秒），完成后按实际秒数结算，多退少补。带不带音轨、开不开 prompt_extend 价格相同。密钥若有分组倍率，再乘该倍率。任务失败不扣费。

参数错误响应

{
  "code": "invalid_request",
  "message": "wan3.0 duration must be -1 or an integer between 2 and 30",
  "data": null
}

状态：queued、in_progress、completed、failed。建议每 15 秒左右查询一次。

completed 后从 result_url（同 metadata.url）下载视频。视频链接为限时链接，请及时下载转存。seconds 为实际输出秒数，size 为实际分辨率。

failed 时读取 error.code 和 error.message，常见 DataInspectionFailed（内容审核未通过）、IPInfringementSuspect（疑似知识产权侵权）、InvalidParameter（参数或素材组合不被接受）。
