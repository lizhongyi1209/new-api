可灵 3.0 Omni 视频生成（多图、多视频参考）和动作模仿。提交后返回 task_id，用对应查询接口取结果。 POST /kling/omni-video/kling-3.0-omni 等，返回 task_id GET …/{task_id} SUCCESS 后读取 video_url

这个接口做什么？

用可灵 3.0 生成视频：Omni 接口可以组合提示词、首尾帧、参考图和参考视频；动作模仿接口让图片中的角色按一段视频的动作动起来。接口先返回任务编号，之后用编号查询。

你需要提供的信息

做什么
Omni 生成用 /kling/omni-video/kling-3.0-omni，动作模仿用 /kling/motion-control/kling-3.0。
提示词和素材
contents 数组：prompt 项写描述，图片、视频项填 url。
画面比例
settings.aspect_ratio：没有首帧或参考视频时必填。

怎么拿到结果

状态
SUBMITTED、IN_PROGRESS 继续等待；SUCCESS 成功；FAILURE 失败。
视频地址
video_url，实际时长见 duration。
  1. Omni 生成 POST /kling/omni-video/kling-3.0-omni；动作模仿 POST /kling/motion-control/kling-3.0。记录返回的 task_id。
  2. 定期 GET 同一路径加 /{task_id}，SUBMITTED 或 IN_PROGRESS 时继续查询。
  3. SUCCESS：把 video_url 返回给用户。
  4. FAILURE：把错误信息告诉用户，不要自动重试。

使用官方 contents、settings、options 结构。无需传 model。

请求参数

字段类型必填说明
contentsarray是提示词、图片和视频输入集合。
contents[].typestring是prompt、first_frame、last_frame、refer_image、feature_video、base_video。
contents[].textstring条件type=prompt 时必填。官方上限 3072 字符，建议不超过 2500 字符。
contents[].urlstring条件图片支持公开 URL 或 Base64；视频使用可公开访问的 URL。
contents[].idstring否任务内唯一的引用 ID，可在提示词中以 @id 引用。
settingsobject条件输出设置。没有首帧或参考视频时必须提供，并填写 aspect_ratio。
settings.multi_shotboolean否是否生成多镜头，默认 true。
settings.audiostring否native 生成原生音频；original 保留参考视频声音；off 无音频。默认 off。
settings.resolutionstring否720p、1080p、4k，默认 720p。
settings.aspect_ratiostring条件16:9、9:16、1:1。没有首帧或参考视频时必填。
settings.durationinteger否3-15 秒的整数，默认 5 秒。
options.callback_urlstring否任务状态变化时接收通知的回调地址。
options.external_task_idstring否调用方自定义且账号内唯一的任务 ID。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。

素材与组合规则

  • 图片支持 JPG、JPEG、PNG，单文件不超过 50MB；宽高均不低于 300px，宽高比在 1:2.5 至 2.5:1 之间。
  • 首尾帧仅支持“仅首帧”或“首帧 + 尾帧”，不支持只传尾帧。
  • 视频支持 MP4、MOV，单文件不超过 200MB，时长 3-15.5 秒；最多传入 1 个参考视频。
  • feature_video 用作特征参考：multi_shot 必须为 true，audio 使用 off。
  • base_video 用作视频编辑：不能同时传首尾帧，multi_shot 必须为 false，audio 可用 original 或 off。
  • 多镜头提示词写法为“镜头序号, 秒数, 描述;”，支持 1-6 个镜头；各镜头时长之和必须等于 settings.duration。

请求体沿用 Kling 3.0 Motion Control 官方结构。每个任务提供 1 张角色外观参考图和 1 个动作参考视频；模型已由路径确定。

请求参数

字段类型必填说明
contentsarray是由提示词、角色图片和动作视频组成。
contents[].typestring是本页展示 prompt、image、video。
contents[].textstring条件type=prompt 时必填，最多 2500 字符；提示词本身可省略。
contents[].urlstring条件图片支持公开 URL 或 Base64；动作视频使用公开 URL。
settings.character_orientationstring是video：朝向跟随动作视频；image：朝向跟随参考图。
settings.audiostring否original 保留动作视频原声；off 无音频。默认 original。
settings.resolutionstring否720p、1080p，默认 720p。
options.callback_urlstring否任务状态变化时接收通知的回调地址。
options.external_task_idstring否调用方自定义且账号内唯一的任务 ID。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。

素材规则

  • 必须且只能传 1 个 image 和 1 个 video。
  • 图片支持 JPG、JPEG、PNG，最大 50MB；宽高均不低于 300px，宽高比在 1:2.5 至 2.5:1 之间。
  • 动作视频支持 MP4、MOV，最大 100MB，宽高均在 340-3850px 之间；建议使用人物完整可见、无遮挡、无切镜、无明显运镜的连续单镜头。
  • character_orientation=video 时动作视频可为 3-30 秒；设为 image 时可为 3-10 秒。
  • video 更适合复杂动作；image 保持参考图朝向，并更适合通过提示词控制镜头运动。
