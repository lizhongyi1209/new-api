11 个按秒计费的视频模型，支持文字生成和图片、视频、音频参考。通过同一个接口提交任务、查询进度和下载 MP4。 选择模型，提供提示词、时长和可选参考素材 用返回的任务 ID 轮询状态 任务完成后，携带 O1Key 密钥下载 MP4

用一张图生成视频

选择分辨率，把图放在可以直接读取的公网网址上，再写下人物动作、拍摄方式和配乐要求。只提供提示词即可做文生视频。

5 秒视频多少钱？

默认分组里，sd-2-mini-480 生成 5 秒为 ¥0.44，sd-2.5-720P 生成 5 秒为 ¥2.189。其他型号按下表的单价乘以计费秒数。
  1. 向 POST /v1/videos 提交 JSON。按下表填写完整模型 ID，使用 prompt 或 content 传入提示词。
  2. 保存返回的 id，轮询 GET /v1/videos/{id}。
  3. 状态为 completed 时携带同一账户的密钥请求 GET /v1/videos/{id}/content 保存 MP4。状态为 failed 时读取 error。

请求参数

  • model 与提示词必填。prompt 描述画面、动作与声音。也可以通过 content 数组传入 text 和 image_url、video_url、audio_url 项。
  • duration（或 seconds）指定整数秒。aspect_ratio 支持 9:16、16:9、1:1、3:4、4:3、21:9。
  • references 的每一项提供 type 和 url，类型支持 image、video 或 audio，普通素材的 role 为 reference。本地文件可先通过 素材上传接口 获取网址。
  • SD 2 最多可传 9 张图片、3 段视频、3 段音频。两款 Fast 支持用 first_frame 指定首帧，再用 last_frame 指定可选尾帧。Fast 的音频参考需要搭配图片或视频。
  • SD 2.5 标准版最多支持 30 张图片、10 段视频、10 段音频，Flash 最多支持 10 张图片、5 段视频、5 段音频。

图生视频 · 竖屏 5 秒

curl https://api.o1key.com/v1/videos \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sd-2.5-720P",
    "duration": 5,
    "aspect_ratio": "9:16",
    "prompt": "正常速度拍摄 5 秒穿搭短片。远景走两步，近景转身展示剪裁，最后特写面料纹理，配欢快无歌词音乐。",
    "references": [
      {"type": "image", "role": "reference", "url": "https://cdn.example.com/outfit.jpg"}
    ]
  }'

提交响应示例

{"id":"task_example","object":"video","status":"queued","progress":0}

用任务 ID 查询状态。queued 表示排队，in_progress 表示生成中，completed 后可下载成片。failed 的任务可通过响应中的错误信息排查。

查询状态

curl "https://api.o1key.com/v1/videos/$TASK_ID" \
  -H "Authorization: Bearer $API_KEY"

完成响应示例

{"id":"task_example","object":"video","status":"completed","progress":100}

保存成片

curl -fL "https://api.o1key.com/v1/videos/$TASK_ID/content" \
  -H "Authorization: Bearer $API_KEY" -o outfit.mp4
