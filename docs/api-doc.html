临时素材上传

上传图片、音频、视频或文档，获取可供模型读取的临时公开 HTTPS URL。

上传单个附件

POST/v1/o1key/uploads

请求使用 multipart/form-data，每次上传一个文件。成功后返回一个有效期为 24 小时的公开 URL，可用于后续图片、音频、视频或文档模型请求。

请求参数

字段必填类型说明
file是binary待上传附件；单文件最大 48 MiB
Multipart 请求：浏览器、SDK 或命令行工具应自动生成包含 boundary 的 Content-Type，不要手动填写固定的 multipart/form-data 请求头。

支持的文件格式

类别扩展名
图片png、jpg、jpeg、webp、gif、bmp、tif、tiff、heic、heif、avif
音频mp3、wav、flac、aac、m4a、oga、ogg
视频mp4、mov、m4v、webm、avi、mkv、mpeg、mpg、ogv、3gp、3g2
文档pdf、txt、md、csv、json、rtf、doc、xls、ppt、docx、xlsx、pptx、odt、ods、odp

服务端会校验文件扩展名与实际内容类型。扩展名与内容不一致、可执行内容以及未列出的格式会被拒绝。

响应字段

字段类型说明
urlstring临时公开 HTTPS URL，直接用于后续模型请求
filenamestring上传时的原始文件名
content_typestring服务端确认后的 MIME 类型
sizeinteger文件大小，单位为字节
expires_atintegerURL 失效时间，Unix 秒级时间戳

URL 使用规则

  • 通过 https://cf-api.o1key.com 上传时，返回 Cloudflare 域名 URL。
  • 通过 https://api.o1key.cn 上传时，返回国内加速域名 URL。
  • 返回的 URL 支持直接 GET 或 HEAD，读取时不需要再次携带 API Key。
  • URL 过期后返回 404。客户端应保存 expires_at，需要继续使用时重新上传。
  • 客户端展示文件名时应使用响应中的 filename，不要从临时 URL 推断原始文件名。
安全提示：临时 URL 在有效期内可公开访问，请勿上传 API Key、密码、身份证件或其他高敏感信息。

错误处理

HTTP 状态码含义客户端处理建议
400请求格式错误、缺少文件、空文件或格式不支持修正请求或提示用户更换文件，不要自动重试
401API Key 缺失或无效检查鉴权配置
403当前凭证无权访问检查账号、凭证或访问策略
413文件超过大小限制压缩文件或选择更小的附件
429请求过于频繁读取 Retry-After 响应头并延迟重试
500服务暂时不可用使用退避策略进行有限次数重试
重试：上传接口不接受幂等键。网络超时后重试可能生成新的 URL，客户端应以最后一次成功响应为准。

  -H "Authorization: Bearer $API_KEY" \
  -F "file=@./reference.png"
const form = new FormData();
form.append("file", file, file.name);

const response = await fetch(

    `上传失败：HTTP ${response.status}` +

}

const upload = await response.json();

请求参数

字段必填类型说明
model是string图片模型名称，填写上方模型表中的完整值。
prompt是string图片生成或编辑指令。
images否array参考图数组。建议显式使用 fileData 或 inlineData；也兼容 URL、Data URI 和原始 Base64 字符串。单张参考图仍放入数组，不要使用 image 字段。
n否integerGPT Image 的生成数量；Gemini 模型无需传入。
size否stringGemini 3 Pro / 3.1 Flash 可选 1K、2K、4K，必须使用大写 K，默认 1K；GPT Image 2 可选 auto 或上方尺寸表中的具体像素值。
aspect_ratio否stringGemini 模型的输出宽高比，取值见上方兼容表。GPT Image 2 的宽高比由 size 决定，无需传入。
quality否stringGPT Image 的生成质量，可选 low、medium、high、auto。
background否stringGPT Image 的背景模式，仅适用于名称以 gpt-image 开头的模型。可选 auto（自动选择背景）或 transparent（透明背景）；使用透明背景时，output_format 必须为 png 或 webp。Banana/Gemini 模型不要传入此字段。
moderation否stringGPT Image 的内容审核强度，仅适用于名称以 gpt-image 开头的模型。可选 auto（标准过滤，默认）或 low（限制较少的过滤）。Banana/Gemini 模型不要传入此字段。
output_format否stringGPT Image 的输出图片格式，可选 png、jpeg、webp。透明背景仅支持 png 或 webp；Banana/Gemini 模型无需传入。
thinking_level否stringGemini 3.1 Flash 的思考级别，可选小写 minimal 或 high；Gemini 3 Pro 不要传入。
response_modalities否string[]Gemini 模型的响应模态。["IMAGE"] 仅生成图片；["TEXT","IMAGE"] 同时生成文字和图片，默认为此值。不要单独传入 ["TEXT"]；任务查询结果仅返回图片。

参考图格式

新接入使用以下两种显式格式；同一数组内可以混用：

格式写法说明
fileData{"fileData":{"mimeType":"image/jpeg","fileUri":"https://.../reference.jpg"}}URL 图片。必须声明图片 MIME 类型和公网 HTTP(S) 地址。
inlineData{"inlineData":{"mimeType":"image/png","data":"..."}}Base64 图片。必须声明图片 MIME 类型；data 不含 Data URI 前缀。
兼容格式：仍接受 URL、Data URI 和原始 Base64 字符串，但新接入应显式声明 fileData 或 inlineData。
大小限制：使用 inlineData 时，Base64 数据、提示词、系统指令和其他参数组成的最终 Gemini JSON 请求体不得超过 20MiB；服务以完成 Base64 编码和 JSON 序列化后的实际字节数为准。使用 fileData 时，图片文件本身不计入该请求体大小；如果 URL 因渠道能力回退为 inlineData，则仍按最终 20MiB 请求体限制校验。URL 必须公网可访问，并要求地址在任务完成前保持有效。

查询生图任务

GET/async/v1/tasks/{task_id}

路径参数

字段必填类型说明
filename是string文件名
content_type是stringimage/*、video/* 或 audio/*
size否integer文件字节数

使用响应中的 upload_url 上传文件，使用 public_url 创建素材。

curl -X POST https://cf-api.o1key.com/v1/storage/presign \

  -H "Content-Type: application/json" \

Seedance 多模态视频生成

POST/v1/video/generations
支持模型：dreamina-seedance-2-0-hc、dreamina-seedance-2-0-fast-hc、dreamina-seedance-2-0-mini-hc、dreamina-seedance-2-5-hc

顶层参数

字段必填类型支持值与说明
model是string选择上方列出的 HC 模型
content是array有序多模态内容数组；本站当前要求至少包含一项有效的 text
duration否integer单位秒，默认 5；2.0 建议 4-15，2.5 支持 4-30
resolution否string默认 720p；具体范围见下方模型表
ratio否string16:9、4:3、1:1、3:4、9:16、21:9、adaptive
generate_audio否boolean是否生成同步音频；传参考音频时建议设为 true
watermark否boolean是否添加可见水印
return_last_frame否boolean是否在任务结果中返回末帧地址，适合续生成

模型与分辨率

模型支持分辨率
dreamina-seedance-2-0-hc480p、720p、1080p、4k
dreamina-seedance-2-0-fast-hc480p、720p
dreamina-seedance-2-0-mini-hc480p、720p
dreamina-seedance-2-5-hc480p、720p

content 多模态项目

类型字段role说明
提示词text不适用{"type":"text","text":"..."}
首帧图image_url.urlfirst_frame首帧生视频时使用；单张图片时也可省略 role
尾帧图image_url.urllast_frame首尾帧生视频时使用，必须同时提供 first_frame
参考图image_url.urlreference_image支持 asset://<素材ID> 或公开 HTTPS URL
参考视频video_url.urlreference_video支持素材 ID 或公开直链
参考音频audio_url.urlreference_audio不能作为唯一参考，需同时传图片或视频
通用限制：最多 9 张参考图、3 个参考视频和 3 段参考音频；2.0 的参考视频 / 音频单段建议 2-15 秒、各自总时长不超过 15 秒。
四种生成方式：多模态参考、首帧、首尾帧和文生视频。首帧、首尾帧和多模态参考互斥，不要在同一个请求中混用 first_frame、last_frame 和 reference_*。

参考图的两种传法

方式适用场景步骤
asset://素材ID真人、数字人、身份一致性；推荐申请上传地址 → 上传文件 → 创建素材 → 等待 Active → 在 content 中引用
公开 HTTPS URL普通公网参考图，调用步骤更少直接填写可匿名下载、无 Cookie 和防盗链限制的图片直链；服务器会为参考图准备上游素材

请求示例

      },
      {
        "type": "image_url",
        "image_url": {"url": "https://cdn.example.com/character.jpg"},
        "role": "reference_image"
      },
      {
        "type": "video_url",

        "role": "reference_video"
      },
      {
        "type": "audio_url",

Gemini Omni 视频

创建 Gemini Omni 视频任务

POST/v1/videos

固定使用 gemini-omni-flash-preview。返回公开任务 ID。

媒体输入：仅接受 Base64 Data URI 或原始 Base64，不接受远程 URL。

请求参数

字段类型必填说明
modelstring是固定为 gemini-omni-flash-preview。
modestring建议text_to_video、image_to_video、reference_to_video 或 edit。不传时会根据媒体字段推断。
promptstring条件文生视频必填；其余模式可选。
imagestring条件单图生视频使用一张 Base64 图片。推荐写成 data:image/png;base64,...。

系统读取上游返回的输入、文本输出、思考和视频模态 Token 分别结算。720p 视频按每秒 5,792 个视频 Token 计量；最终扣费以上游实际用量为准，不按请求中的预估时长直接结算。

Kling VIDEO 3.0

Kling 3.0 Omni 视频生成

POST/kling/omni-video/kling-3.0-omni

使用官方 contents、settings、options 结构。无需传 model。

请求参数

字段类型必填说明
contentsarray是提示词、图片和视频输入集合。
contents[].typestring是prompt、first_frame、last_frame、refer_image、feature_video、base_video。
contents[].textstring条件type=prompt 时必填。官方上限 3072 字符，建议不超过 2500 字符。
contents[].urlstring条件图片支持公开 URL 或 Base64；视频使用可公开访问的 URL。
contents[].idstring否任务内唯一的引用 ID，可在提示词中以 @id 引用。
settingsobject条件输出设置。没有首帧或参考视频时必须提供，并填写 aspect_ratio。
settings.multi_shotboolean否是否生成多镜头，默认 true。
settings.audiostring否native 生成原生音频；original 保留参考视频声音；off 无音频。默认 off。
settings.resolutionstring否720p、1080p、4k，默认 720p。
settings.aspect_ratiostring条件16:9、9:16、1:1。没有首帧或参考视频时必填。
settings.durationinteger否3-15 秒的整数，默认 5 秒。
options.callback_urlstring否任务状态变化时接收通知的回调地址。
options.external_task_idstring否调用方自定义且账号内唯一的任务 ID。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。

素材与组合规则

  • 图片支持 JPG、JPEG、PNG，单文件不超过 50MB；宽高均不低于 300px，宽高比在 1:2.5 至 2.5:1 之间。
  • 首尾帧仅支持“仅首帧”或“首帧 + 尾帧”，不支持只传尾帧。
  • 视频支持 MP4、MOV，单文件不超过 200MB，时长 3-15.5 秒；最多传入 1 个参考视频。
  • feature_video 用作特征参考：multi_shot 必须为 true，audio 使用 off。
  • base_video 用作视频编辑：不能同时传首尾帧，multi_shot 必须为 false，audio 可用 original 或 off。
  • 多镜头提示词写法为“镜头序号, 秒数, 描述;”，支持 1-6 个镜头；各镜头时长之和必须等于 settings.duration。

Kling 3.0 动作模仿

POST/kling/motion-control/kling-3.0

请求体沿用 Kling 3.0 Motion Control 官方结构。每个任务提供 1 张角色外观参考图和 1 个动作参考视频；模型已由路径确定。

请求参数

字段类型必填说明
contentsarray是由提示词、角色图片和动作视频组成。
contents[].typestring是本页展示 prompt、image、video。
contents[].textstring条件type=prompt 时必填，最多 2500 字符；提示词本身可省略。
contents[].urlstring条件图片支持公开 URL 或 Base64；动作视频使用公开 URL。
settings.character_orientationstring是video：朝向跟随动作视频；image：朝向跟随参考图。
settings.audiostring否original 保留动作视频原声；off 无音频。默认 original。
settings.resolutionstring否720p、1080p，默认 720p。
options.callback_urlstring否任务状态变化时接收通知的回调地址。
options.external_task_idstring否调用方自定义且账号内唯一的任务 ID。
options.watermark_info.enabledboolean否是否同时生成带水印结果，默认 false。

素材规则

  • 必须且只能传 1 个 image 和 1 个 video。
  • 图片支持 JPG、JPEG、PNG，最大 50MB；宽高均不低于 300px，宽高比在 1:2.5 至 2.5:1 之间。
  • 动作视频支持 MP4、MOV，最大 100MB，宽高均在 340-3850px 之间；建议使用人物完整可见、无遮挡、无切镜、无明显运镜的连续单镜头。
  • character_orientation=video 时动作视频可为 3-30 秒；设为 image 时可为 3-10 秒。
  • video 更适合复杂动作；image 保持参考图朝向，并更适合通过提示词控制镜头运动。
