## 功能、影响和风险

| 功能 | 影响范围 | 风险与保护 |
| --- | --- | --- |
| 实际计费单位及图片数量 | 消费日志摘要和详情、动态价格表 | 低至中：使用日志实际 billing_unit/fixed_price/image_count，不按查看日志时的当前时间重新计算历史价格；固定零价明确保留，匹配同时核对计费单位和价格 |
| 图片缓存及归一化用量 | 日志用量明细、模型广场缓存列和动态价格详情 | 低至中：显示后端 billing_tokens/image_cache_tokens；图片缓存与普通缓存分列，零系数与缺失区分，不伪造未知命中价格 |
| 按次/图片价格和条件 | 模型广场卡片、列表价格、模型详情及共享动态价格表 | 低至中：fixed 及 image_count 保留计价单位，K/M 不缩放按次价格；结构解析保留带引号的请求条件和图片数量，不以局部非线性解析结果冒充单价 |
| 请求规则命中 | 历史消费日志详情 | 低：显示后端 request_rules 的命中状态；没有在浏览器重新执行历史请求 |
| 四模型内置表达式 | billing_setting 读取、价格配置 API、管理员选项和模型广场 | 中至高：直接关系未来扣费。同步上游 gpt-image-2、两个 gpt-image-2.5 变体及 gpt-6-astra 默认表达式；现有显式 mode、token/按次价格和零价优先。只在没有旧价及显式模式覆盖时采用默认表达式；读取不会写入数据库 |

没有新增业务表、字段或迁移；没有自动转换既有价格或启用插件。内置表达式采用已核查上游基准中的默认配置。未来上线后，符合默认回退条件的这四个模型采用新增表达式；既有管理员价格不被覆盖。

本地定制的历史常量加请求参数图片价格保留旧解析合同；其他不能安全结构化的复杂表达式继续保留原文。当前时间只用于模型广场当前价格，历史日志仍使用结算快照。确认、表格和明细继续复用项目组件，没有新增通用 UI 依赖。
