# 第 5B-2 批条件编辑、模拟和价格转换验收

**本子批代码与必要本地验证已完成，未部署生产。** 上游基准继续使用已全面核查的 `7fd06381976cbea126d1f20973548bf60f20e37d`；第 5B-3 和第 6–8 批仍需实施。

## 功能、影响和风险

| 功能 | 影响范围 | 风险与保护 |
| --- | --- | --- |
| 可视条件树 | 模型定价编辑；时间、长度与 token 条件，且/或/非及嵌套分支 | 中：条件决定未来价格。未编辑源码保留空白、版本、价格顺序及显式零；不支持无损可视编辑的表达式保留原文模式，未完成的价格/条件阻止保存 |
| fixed()、img_cr 编辑及请求模拟 | 表达式价格通道、按次价格、模拟请求体/请求头/时间/图片数量 | 中：价格模拟使用受限 AST 运行时，不执行 JavaScript；输入采用已归一化用量，可覆盖原输入长度；非法和非有限用量报告错误，不冒充免费。插件 u(...) 保留到第 7 批 |
| 生效价格预览 | 两个管理员价格预览 API、编辑器实时预览 | 中：使用独立草稿解析默认值及继承，不修改保存配置或全局倍率；预览失败保留当前页面，旧草稿响应不用于新草稿 |
| 旧价转换确认 | 转换 API、转换前后单价和表达式、应用到草稿 | 中至高：转换仅生成草稿，仍须明确保存才生效；保存沿用已有版本冲突校验。保留通用缓存写入 1.25、Claude TTL、音频独立结算及图片请求倍率等本地行为 |

币种输入继续复用第 5A 批 USD 状态及精度控制。确认与复制继续使用项目 ConfirmDialog/CopyButton；JSON 编辑使用已有 JsonEditor/JsonCodeEditor，没有新增通用弹窗或编辑器依赖。七语言新增 27 条文案，通过技能要求的临时 add-missing-keys.mjs 写入并执行 i18n:sync，临时脚本已删除。

没有新增业务表、字段或迁移；预览查询及现有保存使用 GORM，没有新增方言专属 SQL。实际数据库验证为隔离 SQLite，不宣称执行了 MySQL/PostgreSQL 集成测试。新增路由使用现有 RootAuth，普通用户访问拒绝；没有改变登录或会话机制。

自动转换对 Realtime、视频/原生任务、无法核实的路由、渠道间倍率不同、OpenRouter Claude 上游费用反推缓存、无法安全推导的 Claude/图片别名及接口间音频价格冲突提供明确的手动转换提示。不会悄悄丢弃这些计费条件。表达式与旧计费的预扣/舍入合同不同，单笔舍入额度可能有差异，转换确认明确说明。
