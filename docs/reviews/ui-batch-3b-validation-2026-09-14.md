## 改动、影响与风险

| 改动 | 影响范围 | 风险及保护 |
| --- | --- | --- |
| 业务失败进入 error 状态 | 渠道、密钥、模型/供应商/部署、模型广场、日志、概览及相关只读资料查询；主要编辑保存流程 | 中：success:false 不进入成功回调、不清除有效查询数据；保留原始 Axios 响应合约、业务错误码和供应商引用数量 |
| 提示归属与时机 | 公共 QueryClient、普通 HTTP 错误和直接操作 | 中：普通拦截器不抢先提示，由最终查询失败或局部处理提示；同一错误及其包装只提示一次；取消静默；局部表单/可选诊断可关闭公共提示及 500 跳转 |
| 编辑和详情隔离 | 渠道/用户编辑、日志用户详情弹窗 | 中：资料未加载成功时禁止提交；用户资料和详情在关闭或切换目标后忽略旧响应；权限目录不可用时保留未提交权限的语义，不用空目录重算已有权限 |
| 直接操作失败处理 | 渠道启停/复制/删除/模型发现、模型可见性、密钥删除、兑换码、亲和性缓存清理、日志维护等 | 中：业务或传输失败不显示成功、不触发成功后的关闭/刷新；保持原有允许部分成功的批量操作和实际成功数量 |
| 公共内容重新校验 | 公告、关于、首页内容、协议、隐私五个只读接口 | 低至中：内容 ETag、304 和 no-cache；保留 Vary: Origin 并追加 Accept-Encoding；私有请求继续 no-store |
| 旧地址兼容 | 非登录 /console 入口及设置 tab | 低至中：保留查询参数重复值和 hash；目标仍使用既有权限与路由；登录入口迁移归第 6 批 |

没有新增业务表、迁移、服务端业务写入接口或修改数据库字段、计费算法。现有客户端请求体、渠道类型编号、本地配置字段和媒体输出策略保留。原认证刷新、重试、一次性证明处理未改变；401 仍显示原有会话失效提示，仅标记已展示以避免后续重复提示。移除涉及调用方的完整 Axios 错误日志，避免把请求配置随错误输出。
