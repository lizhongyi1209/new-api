## 影响范围与风险

| 改动 | 影响范围 | 风险与边界 |
| --- | --- | --- |
| 收集表达式原始 AST 引用的请求头并冻结 | `pkg/billingexpr/compile.go`、异步共享预扣、任务快照 JSON、任务实际结算 | 高：请求条件改变会影响实扣；只保存引用的普通请求头，名称统一为小写，缺失值冻结为空字符串，不复制 Authorization/Cookie 等凭证头 |
| 阻断凭证头和动态请求头名的异步价格 | 三个图片提交入口的表达式预扣前检查 | 中至高：这类异步表达式返回 400，不创建任务或调用上游；未选中分支也检查。同步表达式运行规则保留 |
| Gemini 原生请求保存生成参数投影 | `/async/v1beta/models/{model}:generateContent` 的计费 body 与数量预估 | 高：条件分支和数量直接影响费用。保存标准 camelCase 生成设置及模型、数量、serviceTier；剥离 contents、schema、speechConfig、任意 imageConfig 扩展内容，显式零值保留 |
| Gemini 输入/缓存/输出模态统一提取 | `generateImage`、原异步图片、原生 Gemini worker；共享实际结算 | 高：缓存重叠可能重复收费；累加多条 IMAGE 明细并保留缓存模态的存在性。缺失缓存明细沿用 aggregate 回退；不改变无新单位字段的旧任务归一化 |
| 原生数量及输出 token 边界 | 共享 Gemini 请求验证、提交预扣前 | 高：候选数量限定为 1–128，输出 token 复用共享上限；拒绝发生在预扣前。响应计数与求和使用集中额度转换，避免裸 int 转换溢出 |

没有新增业务表或修改表结构。变化使用已有任务 JSON 的可选字段；没有调整生产模型价格或路由。受控模型使用项目已有的 nano-banana 原生图片分发规则。
