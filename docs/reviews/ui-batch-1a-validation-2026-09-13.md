| 功能 | 实现结果 | 影响及风险 |
| --- | --- | --- |

| 定制版本识别 | `v1.0.0-rc.16-custom` 明确提示无法自动比较，显示上游发布可查看 | 不把定制版本误判为最新或直接认定需要完整升级；发布版本号不代表已移植全部功能 |

| 手机筛选折叠 | 渠道与日志复用折叠面板，筛选折叠后视图/查询等操作继续可用 | 公共表格工具栏仅在渠道显式启用；日志保留筛选抽屉、统计及原有操作。渠道仍为已有实时搜索行为 |
| 任务基础详情 | 桌面列和手机卡片新增入口，显示状态、时间、原始/实际模型；管理员补充请求/上游任务标识、额度等诊断 | 普通用户和管理员“仅看自己”使用已有列表字段；管理员视图复用现有 `/api/task/:task_id/audit`。遵守身份隐藏开关，不展示原始请求/响应快照 |

本批风险仍为**低至中**，主要是公共界面兼容和详情权限。后端代码、数据库结构、渠道保存、转发和计费链路不属于本批改动范围，因此无需新增数据库迁移。

## 修复的真实回归

- 新任务详情列使用稳定的组件入口，避免表格重渲染卸载弹窗、取消请求。
- 任务诊断查询由 React Query 管理取消和去重，避免快速关闭/重开复用已取消的 HTTP 请求。
- 诊断失败由详情内错误状态承接；HTTP 500 不跳转全页错误页，取消请求不弹出失败通知，重试可恢复诊断内容。原有认证刷新仍由请求层处理。
- 手机任务卡片显式挂载详情列，保证新增入口可达。

当前工作区原有 `web/default/dist/static` 含其他所有者的旧文件，默认目录构建后不能据此判断资源齐全。本次另行构建至完全独立的 `/tmp` 目录，核实 HTML 引用的脚本实际存在，再以该产物完成浏览器验收。未删除原目录，也未用该旧目录执行上线。
