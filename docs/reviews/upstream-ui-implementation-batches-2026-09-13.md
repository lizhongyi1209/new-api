## 每次交付的审查材料

1. 本批完成的功能与对应页面，涉及的后端/API、配置或表结构。
2. 手机/桌面、主题、权限和相关业务回归结果；实际前端变更的类型、lint/format 和构建结果。
3. 当前定制功能兼容结果，尤其是渠道保存、媒体输出、视频/异步图像任务和计费。
4. 遗留问题及回退方法；迁移或新增数据存在时明确数据回退限制。

2026-09-14 用户收紧验证标准：测试保持专注简洁，风险以线上用户功能、权限/数据隔离、数据库及计费等业务影响为主；纯 UI 展示、排版和文案正确性无需严格测试或浏览器验收。保留项目要求的代码、类型、lint/格式、翻译和构建检查，已有历史结果如实记录，后续不扩展视觉检查。以上标准优先于此前表中的视觉验收建议。

中、高风险子批次在独立本地测试环境验证，使用隔离数据库和测试配置；支付使用测试方式，渠道发现和任务执行使用受控测试上游。每个子批次单独汇报，不以类型检查或构建通过代替业务验证。

代码与验证完成后提供具体结果，不以计划代替交付。部署后记录实际运行 revision、健康状态与相关验证；Docker 构建后按项目要求清理构建缓存。
