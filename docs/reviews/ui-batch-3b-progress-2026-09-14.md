## 本轮业务页面接入

本轮接入渠道、密钥、模型/供应商/部署、模型广场、日志、概览及资料查询的失败边界。主要保存流程在 success:false 时拒绝，不继续执行成功回调；查询失败保留上一次有效缓存。保留供应商冲突码和引用数量等业务错误信息。

渠道和用户编辑增加资料加载保护：目标资料未加载成功时禁止提交；用户资料请求在关闭或切换后返回时不覆盖当前表单。权限目录加载失败时不提交经过空目录重算的权限。模型、供应商详情与可选诊断可以单独关闭公共提示和 500 跳转。此次调整影响前端查询和提交条件，风险为中；没有改动服务端认证、权限判断、数据库结构或计费算法。
