## 功能、影响和风险

| 功能 | 主要影响范围 | 风险与验收依据 |
| --- | --- | --- |
| fixed()、显式零价及 token/按次条件分支 | `pkg/billingexpr/`、同步/异步预扣及实际结算 | 高：直接扣费。有限非负常量与单一计价叶验证、未选中非法分支阻断；实际固定价、零价、混合两个分支均有账目证据 |
| img_cr 图片缓存价格 | 输入 DTO、OpenAI/Gemini 用量处理、共享 token 归一化 | 高：重叠可能重复扣款。校验缓存/图片/输入总量及 text/audio 明细；缺失/非法明细回退旧规则，显式零值与未提供区分 |
| 请求条件、计费单位和数量快照 | 三个异步图片提交入口、任务已有 JSON | 高：提交和完成条件必须一致。保存引用的普通请求头、价格标量和原生生成设置；内容与媒体不进入价格投影；实际返图数量应用一次 |
| 零价释放预扣及旧任务兼容 | 钱包/订阅、令牌、渠道、原消费日志 | 高：退款与统计必须一致。新单位字段缺失的历史任务保留旧归一化/长度；成功零价恢复预扣，通用倍率的零值跳过合同保留；失败退款遵守已有政策 |
| 音频及 Responses 输出明细 | `service/quota.go`、`text_quota.go`、普通/流式/compact Responses 响应归一化 | 高：模态丢失会造成错误实扣。复制 DTO 已支持的输出明细；fixed 请求不因没有 token usage 免费，旧 token 零用量退款合同保留 |
| 饱和额度审计 | 异步差额结算、日志已有 admin_info JSON | 中至高：异常必须可查。补充请求关联警告，三个日志更新函数按字段合并管理员信息，使额度饱和标记保留到完成日志；非管理员投影继续去除 admin_info |
| 非法数量/价格与未支持能力阻断 | 请求验证、价格保存、预扣前边界 | 中至高：越界返回 400，不扣费或访问上游；Realtime 不支持 fixed，未配置 usage-schema 的 u(...) 暂不开放；没有自动转换旧价格 |

没有新增业务表或修改表结构。任务快照和日志增加可选 JSON 字段，数据库写入继续使用已有 GORM 方法；没有增加特定数据库 SQL。实际运行验证使用隔离 SQLite，未声称运行了 MySQL/PostgreSQL 集成测试。`relaykit/` 未修改，生产配置、价格、媒体策略和运行容器未切换。

## 本阶段实际请求与账目

专用容器 `new-api-ui-batch-5b1` 只监听 `127.0.0.1:3332`，使用独立卷、合成账号/受限令牌及受控上游。New API HTTP 请求使用 newapi 技能 `api.js`，没有真实上游或付款。候选 Go 构建后复用缓存镜像，没有 Docker 镜像构建。最终运行二进制与宿主候选一致，SHA-256：`45fc8654ffc41f2d954f9c841bb289f867a8a2b85838b7c3e409abeef8de89c5`。

| 实际案例 | 入口 | 最终额度 |
| --- | --- | ---: |

| PCM 音频显式免费 | 同上 | 0 |

共 **14 个实际请求**：9 个音频、4 个图片用量、1 个额度饱和任务。音频模态手算：输入 100（音频 40）、输出 50（音频 20），`p=60,c=30,ai=40,ao=20`，`(60*2+30*10+40*3+20*5)/1e6*500000=320`。PCM 案例为 `(1*2+17*2)/1e6*500000=18`。四个新增图片案例均解码消费日志 expr_b64，并核对 `p=300,cr=200,img=300,img_cr=200,img_o=200,c=0` 的手算 **2,110** 与实扣。

普通合成账号本阶段新增实扣 **59,418**，承接此前异步阶段后，钱包/令牌均剩余 **9,842,182**，used_quota **157,818**；两个渠道分别累计 **131,488 / 26,330**，合计 **157,818**，请求数 **27**。消费日志减原有退款日志的净额也是 **157,818**。

额度饱和使用独立合成账号、令牌和渠道，初始额度恰为 MaxInt32，完成后钱包/令牌均为 **0**、used_quota **2,147,483,647**，渠道和日志相同，请求数 **1**。没有用负钱包掩盖转换错误。任务状态 SUCCESS，完成日志同时包含 generate_image_timing 和 quota_saturation，并确认只有一条关联原请求 ID 的警告。令牌耗尽后查询任务会被现有认证规则拒绝，完成证据取自该隔离账本，没有放松认证。

首次音频实请求发现普通 Responses 丢失输出明细：同一音频用量实扣 370 而非 320。复制已存在的 OutputTokensDetails 后，普通、流式、compact 处理器和实际请求重新核对通过。兼容上游的模态扩展字段已是网关 DTO 合同；这不宣称所有官方 OpenAI Responses 模型支持或报告音频/图片 token 字段。本批未改 STT 上传和识别适配器，其无音频明细分支复用共享文本结算；没有追加所有媒体协议/所有提供商的上传验收。
